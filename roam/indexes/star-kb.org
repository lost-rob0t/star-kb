* Purpose
Star KB is the shared symbolic reasoning layer used by StarIntel actors and services. Canonical StarIntel JSON remains authoritative; Star KB deterministically projects that corpus into modular Prolog facts and safe reasoning tools.

* Current phase
Research plus the Prolog projection/query and actor-learning-loop designs are approved. Active bounded implementation now includes:

- =prolog-star-kb=: canonical JSON -> lossless Prolog facts + semantic indexes + AI reasoning tools.
- =star-kb-actors=: append-only candidate/query replay, actor voting, bounded review context, StarLang protocol source, and formal Prolog admission.

Bulk generated candidate staging is authorized. Bulk canonical promotion or uncontrolled real-world ingestion remains blocked.

* Roadmap
1. Verify deterministic JSON -> Prolog projection and safe AI tool compiler.
2. Add SWI-Prolog CI smoke coverage.
3. Add query-server transport around the bounded semantic predicates.
4. Generate MCP and Agent2Agent surfaces from the same tool catalog.
5. Add StarLang =kb=, =reason=, and RLM bindings.
6. Add engine adapters chosen by semantic capability.
7. Grow domain semantic indexes without sacrificing lossless generic projection.
8. Run the actor learning loop over generated candidate datasets and query logs.
9. Generate downstream bindings from the canonical StarLang learning protocol.
10. Only then begin controlled canonical corpus promotion/materialization.
