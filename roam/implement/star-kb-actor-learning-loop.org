* Implemented
- StarLang learning protocol source under =spec/=.
- Six actor contracts for ingest, review, voting, formal verification, audit, and optimization.
- Append-only local event store with a disposable/rebuildable SQLite replay index.
- Single and streaming NDJSON candidate staging with batched index updates.
- Latest-vote replay semantics while preserving vote history.
- Query observation logging, bounded review-context export, and deterministic learning audits.
- Formal SWI-Prolog admission verifier.
- Exact StarLang spec ID/version/source-digest and StarIntel schema adherence checks.
- Source/evidence integrity and voting quorum checks.
- CLI entry point =tools/star-kb-actors=.
- Unit and SWI-Prolog integration tests.
- Runtime event log excluded from Git.

* Not implemented in this slice
- LLM-provider invocation. Actors/runtime provide that externally.
- Automatic promotion into canonical StarIntel JSON.
- Distributed event-log storage.
- Cryptographic actor signatures.
- Generated downstream bindings until StarLang compiler emits the portable manifest for this spec-library through the final compiler surface.
