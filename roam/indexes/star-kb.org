* Purpose
Star KB is the shared symbolic reasoning layer used by StarIntel actors and services. Canonical StarIntel JSON remains authoritative; Star KB deterministically projects that corpus into modular Prolog facts and safe reasoning tools.

* Current phase
Research, the Prolog projection/query design, and the long-term evidence-maturity design are approved. The active bounded implementation is canonical JSON -> lossless Prolog facts + semantic indexes + bounded AI reasoning tools + explicit-link maturity/contradiction/history reasoning.

No bulk real-world ingestion is authorized in these slices.

* Roadmap
1. Verify deterministic JSON -> Prolog projection and safe AI tool compiler.
2. Add SWI-Prolog CI smoke coverage.
3. Add query-server transport around the bounded semantic predicates.
4. Generate MCP and Agent2Agent surfaces from the same tool catalog.
5. Add StarLang =kb=, =reason=, and RLM bindings.
6. Add engine adapters chosen by semantic capability.
7. Grow domain semantic indexes without sacrificing lossless generic projection.
8. Add bitemporal, hypothesis/falsifier, source-independence, and incremental-materialization layers.
9. Generate actor evidence-collection plans from missing proof obligations.
10. Only then begin controlled corpus ingestion/materialization.
